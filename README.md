# Swinglo 官网

静态网站，使用 GitHub Pages 和 GitHub Actions 部署。推送到 `main` 后会自动构建并发布；仓库 Settings → Pages 的 Source 需选择 GitHub Actions。

- 官网： https://yuhongda.github.io/swinglo-doc/
- 中文隐私政策： https://yuhongda.github.io/swinglo-doc/privacy/
- English privacy policy: https://yuhongda.github.io/swinglo-doc/privacy-en/

本地预览：`jekyll serve --baseurl /swinglo-doc`，然后打开终端显示的地址。网站图片来自 Swinglo iOS 项目。隐私政策应在 App 发布前根据实际数据处理和法律要求复核。
